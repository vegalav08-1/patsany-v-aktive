# Кантемировская 3D — версия 1.0

Отдельная тестовая 3D-версия «Пацаны в активе». Существующая 2D-игра в корне репозитория сохраняется.

Игровой квадрат 100 × 100 м, центр: 55.633587, 37.654592. По данным OpenStreetMap точка находится в доме Пролетарский проспект, 18 к3. Игра проходит в прилегающем дворе. Вход в метро в квадрат не входит.

Контуры зданий, этажность, дорожки и положения подъездов основаны на OpenStreetMap. Фасады, озеленение, машины и игровые бизнесы — художественная интерпретация. Это не цифровой двойник и не фотореалистичная реконструкция. Реальные организации не связаны с игровыми бизнесами.

Четыре объёмных персонажа с фотографическими текстурами лиц из предоставленного пользователем фото. Профили и тела приблизительные, не 3D-сканы. Пять минут игры: заказы, выручка, пять приобретаемых активов, доход, пять образов и атрибутов, результат и локальные рекорды.

Движение: экранный джойстик или WASD/стрелки. Камера: перетаскивание свободной части экрана. Действие: кнопка или E. Пауза останавливает время и доход.

Сайт статический. Нет сервера, аналитики, платежей, регистрации, сетевой таблицы или внешних ресурсов во время игры. Экономика условная и намеренно ускоренная.

## Запуск

После подготовки локальных ресурсов: `npm run build`, затем `npm run preview`. Проверки: `npm run check` и `npm test`.

Публикация и браузерные проверки будут отражены в отчёте QA по фактически выполненным запускам. Не считать этот промежуточный коммит готовой публикацией.
