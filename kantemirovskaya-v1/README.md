# Кантемировская 3D — визуальное обновление 1.1

Та же пятиминутная игра и квадрат 100 × 100 м с центром 55.633587, 37.654592, но с переработанным изображением. Оригинальная 2D-игра не изменяется.

## Что изменено

Непрерывная трёхмерная модель человека со скелетом и отдельными материалами кожи, волос, ткани и обуви заменяет модель из примитивов. На лицах — обработанные фотографические текстуры четырёх участников. Одежда дополняется воротниками, лацканами, швами, часами, телефоном и портфелем.

У зданий появляются углублённые окна, объёмные рамы, подоконники, балконы, перила, водостоки и кондиционеры. Для асфальта, травы, штукатурки и коры используются локальные PBR-карты цвета, нормалей, шероховатости и затенения. Деревья состоят из стволов, ветвей и вырезанных по контуру листьев вместо шарообразных крон. Добавлены травяные пучки и люки.

Автомобили имеют закруглённые кузова, наклонные стёкла, колёса с дисками, зеркала и фары. Небо и освещение окружающей среды используют HDR-изображение. Обновлены солнечный свет, тени, камера и материалы. В режиме «Выше» включается дополнительное экранное затенение SSAO; в «Балансе» и «Легче» оно отключено.

## Границы результата

«В пять раз реалистичнее» не является измеримой характеристикой; сравнивать следует реальные кадры игры. Это не фотореалистичная реконструкция и не 3D-сканы участников. Геометрия района основана на прежних данных OpenStreetMap; фасады, растительность, транспорт и бизнесы художественные. Вход в метро не входит в игровой квадрат. Физические телефоны и их FPS не проверены автоматически.

## Запуск

Все ресурсы локальны. Node.js 20+; установка npm-пакетов не требуется:

```sh
npm test
npm run build
npm run preview
```

Открыть localhost:4173. Папка dist — готовый статический сайт. База данных, VPS, ключи API и runtime-CDN не нужны.

Телефон: слева джойстик; свободная часть экрана — вращение камеры; справа — действие. Компьютер: WASD/стрелки, мышь, E/пробел. Качество меняется в паузе. Данные и рекорды остаются в браузере.

## Проверки и лицензии

Модель экономики проверяется tests/model.test.js; tests/browser.py выполняет ускоренные браузерные проверки игры на четырёх размерах экрана. tests/visual.py сохраняет настоящие WebGL-кадры, в том числе режим высокой детализации. Тестовый API работает только на localhost с ?test=1.

Итоги конкретного прогона следует читать из reports/browser.json и reports/visual/report.json, а не выводить из наличия тестов.

Лицензии геометрии и материалов — в licenses/ASSETS.md. MakeHuman CC0 относится только к использованным данным, код приложения MakeHuman не используется. Poly Haven — CC0, Three.js — MIT, OpenStreetMap — ODbL. Фотографии участников не входят в эти свободные лицензии.
