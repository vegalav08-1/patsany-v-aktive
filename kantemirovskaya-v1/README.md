# Кантемировская 3D — версия 1.0

Небольшая самостоятельная 3D-игра «Пацаны в активе». Исходная 2D-игра в корне репозитория остаётся без изменений. Новый сайт собирается отдельно и публикуется в подкаталоге `/3d/` существующего GitHub Pages.

## Что реализовано

Четыре объёмных анимированных героя с лицами из предоставленного пользователем фото. Имя выбирается локально. Пятиминутный раунд: начинаешь с нулём рублей, выполняешь заказы, собираешь выручку, покупаешь пять бизнесов. Купленные активы приносят доход и меняются визуально. Пять уровней капитала открывают новую одежду, часы, смартфон, портфель и припаркованный премиальный автомобиль.

На финише — капитал, активы, заказы, локальный рекорд и PNG-карточка для отправки друзьям. Общей онлайн-таблицы нет.

## Место и графика

Квадрат 100 × 100 м, центр: **55.633587, 37.654592**. По данным OpenStreetMap точка попадает в дом **Пролетарский проспект, 18 к3**. Действие сосредоточено в дворе между пятиэтажками западнее центра; сами дома препятствуют перемещению. Вход в метро в квадрат не входит. За границей игровой зоны отображается упрощённое окружение.

Контуры домов, этажность, подъезды и дорожки основаны на OpenStreetMap. Фасады, деревья, автомобили, павильоны и их размещение частично художественные. Реальные организации не связаны с вымышленными игровыми бизнесами.

Это **стилизованный прототип, не фотореализм и не цифровой двойник**. У героев объёмные тела и головы с фотографической лицевой текстурой. Профили и пропорции приблизительные, это не 3D-сканирование. Нет интерьеров, вождения, сетевого мультиплеера или полной городской симуляции.

## Управление

На телефоне: левый круг — движение; перетаскивание свободной части экрана — камера; кнопка справа — заказ или покупка. Кнопка со стрелкой разворачивает камеру.

На компьютере: WASD в английской раскладке или стрелки; E / пробел — действие; мышь — камера; колесо — расстояние; Escape / P — пауза.

Начни со стенда «Заказы по району», отмеченного золотым кругом. Доход начисляется только во время активной игры. Пауза, скрытие вкладки и открытие портфеля останавливают время и доход. Капитал — наличные плюс стоимость купленных активов, покупка сама по себе не увеличивает богатство. Экономика вымышленная и специально ускорена.

Звук и качество графики переключаются в паузе. На слабом устройстве выбери «Легче». Частота кадров на физических телефонах не измерялась.

## Локальный запуск

Нужен Node.js 20 или новее. Все ресурсы уже находятся в проекте, `npm install` не требуется.

```sh
cd kantemirovskaya-v1
npm test
npm run build
npm run preview
```

Открыть `http://localhost:4173/`. Двойной клик по HTML не заменяет HTTP-сервер для модульного JavaScript. Для разработки: `npm run dev`, затем пересборка после изменений.

`dist/` — весь готовый статический сайт. Его можно поместить на статический хостинг. VPS, база данных и ключи API не нужны. Во время запуска нет CDN-зависимостей.

## Проверка и публикация

`tests/model.test.js`: 14 тестов экономики, паузы, завершения, перезапуска и столкновений с реальной геометрией карты.

`tests/browser.py`: Chromium, размеры 1366×768, 390×844, 360×640 и 844×390; реальный WebGL, клавиатурный/сенсорный ввод, заказ, покупка, доход, пауза, результат, PNG и перезапуск. WebKit проверяется отдельно. Изменения времени и позиции для ускоренного прохождения отмечены тестовым API, который доступен только на localhost с `?test=1` и отсутствует на публичном сайте.

Последние фактические результаты и скриншоты находятся в артефакте `kantemirovskaya-v1-qa` workflow **Kantemirovskaya 3D QA**. Это автоматизация браузеров, не проверка физических iPhone/Android и не замер их FPS.

Workflow публикации сохраняет исходную игру в корне, копирует новую сборку в `dist/3d/`, разворачивает GitHub Pages и проверяет HTTP 200 для обеих страниц и ключевых 3D-ресурсов. До успешного завершения deploy ссылка не считается опубликованной.
